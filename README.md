## 👋 About Me

I'm **Temitope**, a web developer and designer from Nigeria 🇳🇬. I build fast, responsive and good-looking websites and web applications, mostly with **Laravel (PHP)**, **TypeScript** and **JavaScript**.

I'm the founder of **[DevLuxe Studio](https://www.devluxestudio.site/)**, a **CAC-certified** web design and development studio where I build digital products for businesses and individuals.

- 💻 Building robust backends and full-stack apps with **Laravel & PHP**
- ⚡ Crafting modern frontends with **TypeScript, JavaScript & React**
- 🎨 Designing clean, modern interfaces people enjoy using
- 🤝 Open to freelance projects, client work and collaborations
